# Documentation d'avancement

Ce dossier journalise l'implémentation du projet, phase par phase. Chaque fichier
décrit une évolution : ce qui a été construit, les décisions prises et pourquoi,
et l'état résultant (ce qui marche, ce qui reste à faire).

- [`phase1/`](./phase1) — Phase 1 (MVP) : chat + mémoire + profil utilisateur.
- [`phase2/`](./phase2) — Phase 2 : agent, tools, planification, actions.
- [`phase3/`](./phase3) — Phase 3 : automatisations proactives, dashboard.
- [`checklist-test-manuel.md`](./checklist-test-manuel.md) — tests fonctionnels
  manuels à faire en complément de la suite `pytest` automatisée.
